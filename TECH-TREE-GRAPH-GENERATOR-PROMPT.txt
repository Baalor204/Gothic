Generate a Mermaid flowchart showing the FULL RECURSIVE dependency tree for the target tech.

CRITICAL RULES (NON-NEGOTIABLE)
────────────────────────────────────────

- You may ONLY use dependencies explicitly present in the dataset.

- NEVER assume symmetry or reverse edges.

  - Extract its 10 prerequisite IDs.
  - For each non-zero ID:
    - Find the matching tech line.
    - Add it as a node.
    - Recursively expand THAT node as well.
- Continue until all reachable nodes are fully expanded.

3. TERMINATION CONDITION
Stop recursion ONLY when:
- A node has no non-zero prerequisite IDs.

4. NO DEPTH LIMIT
- Do NOT stop at depth 1 or 2.
- Must compute FULL transitive closure.

5. DEDUPLICATION
- Each tech node appears only once in the graph definition.
- Multiple incoming edges are allowed, but no duplicate node declarations.

6. NODE FORMAT
Each node must be:
ID + Tech Name
Example:
T92["Inquisitor (92)"]

7. EDGE DIRECTION
Edges ALWAYS point:
prerequisite → dependent tech
(i.e., dependency flows INTO the target tech)

- Ignore any 0 values in stats arrays.
